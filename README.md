# SSAFY 7 TAROT

SSAFY 동료들이 타로를 통해 고민을 정리하고 생각과 감정을 기록할 수 있도록 만든 개인 프로젝트입니다. SSAFY 공식 서비스가 아닙니다.

## 실행
별도의 빌드, npm 설치, API 키, 백엔드 설정이 필요 없는 HTML/CSS/JavaScript 사이트입니다.

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. Windows에서는 `py -m http.server 8000`도 사용할 수 있습니다. `index.html`을 직접 열어도 주요 기능을 사용할 수 있으나, 복사 등 브라우저 권한 동작은 실행 환경에 따라 다릅니다.

## 구성
- `index.html`: 사이트 전체. 카드·커버 이미지가 내장되어 약 10MB입니다.
- `AGENTS.md`: Codex 등 코딩 도구가 참고할 프로젝트 지침입니다.

## 현재 기능
- 질문 작성, 스프레드 선택·검색·분류, 카드 셔플·선택
- 데일리, 3카드, 켈틱 크로스, 관계·재회, 선택지 A/B 비교, 매직 세븐 등 15개 스프레드
- 역방향·애니메이션·사운드 설정과 처음 이용 가이드
- AI 해석 요청문 복사·텍스트 저장·ChatGPT/Gemini/Claude 이동
- 최근 리딩 저장과 리딩 저널
- 결과 화면의 포춘쿠키 50종

사이트가 AI API를 호출하지는 않습니다. 사용자가 생성된 요청문을 외부 AI 서비스에 붙여넣고 해석을 받습니다. 최근 리딩·저널·설정은 브라우저 로컬 저장소를 사용하므로 다른 기기나 도메인으로 자동 동기화되지 않습니다.

## 개발
GitHub의 이 저장소를 작업 기준으로 사용합니다. 변경 후 데스크톱·모바일 화면과 카드 선택, 결과, 복사, 저장 흐름을 확인합니다. 실제 브라우저로 검증하지 못한 항목은 구분해서 기록합니다.

Codex에서는 이 저장소를 선택하거나, 로컬에 clone한 폴더를 프로젝트로 열어 작업할 수 있습니다. GitHub 연결과 Codex 환경 선택은 사용하는 Codex 화면에서 설정합니다.
